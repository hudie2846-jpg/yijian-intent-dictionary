후보: 기사 전체 숫자 검증. 근거: 지정 보고서 2개만. 웹 검색 금지. [O 23 / C 33]

확인: 모든 숫자; 두 보고서만; 외부 검색 없음

### 모의와 실제

원뜻: 기한 지난 기록을 삭제한 결과를 모의 실행하되 데이터베이스는 실제로 수정하지 않는다. [O 24 / C 33]

후보: 만료 기록 삭제 후 결과 모의 실행. 실제 DB 수정 금지. [O 16 / C 20]

확인: 모의 결과; DB 변경 없음

## 공개판 안내

### 변경 내용

네 언어판에 실제 토큰 수를 표시했습니다. 읽기용 문서와 데이터의 항목 ID와 장 번호를 없애고 중국어판의 영어 대조 열을 삭제했습니다. 네 언어 사용법도 추가했습니다.

### 측정 상태

tiktoken으로 o200k_base와 cl100k_base를 각각 실측했습니다. 다른 토크나이저 수치를 이 두 값에서 추정하지 않습니다.

### 번역 상태

영어, 일본어, 한국어는 AI 보조 초안입니다. 독립 원어민 교정과 여러 모델의 실행 검증은 아직 하지 않았습니다.

### 복사와 추가 비용

필요한 표현만 복사하고 숫자 표시나 사전 전체는 복사하지 않습니다. 해석 카드가 필요하면 전체 입력 계산에 포함합니다.

### 기여 방법

원뜻, 후보, 범위, 반례, 정확한 측정 원문과 토크나이저 버전을 제시하세요. 작업 효과 주장에는 별도의 실행 증거가 필요합니다.

### 라이선스와 저자

이 공개 후보판은 오픈소스 라이선스와 개인 저자명을 지정하지 않았습니다.

### 측정 근거

tiktoken 공식 프로젝트와 공식 계산 예시를 참고했습니다. 표시된 값은 이번 로컬 실행으로 얻었습니다.
